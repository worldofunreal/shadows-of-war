# Inventario de bots de tribu

El catálogo registra **400 bots de tribu**. Este inventario se deriva de [`assets/geo_entities.json`](../assets/geo_entities.json), que es la fuente canónica; actualiza esa fuente antes de regenerar esta lista.

Se incluyen entradas con `role: tribe` sin datos de héroe jugable. Los héroes tribales jugables están excluidos porque el juego no los cuenta como bots de tribu.

## Cantidad por región

- Américas: 97
- Asia: 112
- África: 80
- Europa: 80
- Oceanía: 31
