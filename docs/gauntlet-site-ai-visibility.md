# Gauntlet Loop — shadowsofwar.io (AI visibility)

**Target:** `sow-web/site/index.html` + siblings (`play`, `support`, `privacy`, `terms`, `cookies`), the generated `robots.txt` / `sitemap.xml`, and the static build output.
**Goal:** a first-time human and a blind AI crawler both answer *"what is Shadows of War, who makes it, how do I play it, is it free"* correctly from the HTML alone — then click Play.
**Non-goals:** redesigning the art direction, inventing player counts / review scores / revenue, touching gameplay code, or "SEO copy" that no human would read.

Method: builder/critic loop (Matt Shumer's Gauntlet). N rounds × 5 adversarial critics × hard gate. The builder never grades itself.

---

## 0. Contract (read before round 1)

1. **Source of truth is `sow-web/site/`, never `dist/`.** `dist/` is regenerated by `./sow l` / `./sow p`.
2. **Every claim must be verifiable** by a command or a file:line. "Mejora la claridad" is not a finding.
3. **No invented facts.** Names, dates, platform availability, pricing = whatever the repo already states. If it is not in the repo, it does not ship.
4. **The human page wins ties.** If a crawler fix makes the page read worse for a player, the fix is wrong; find another way (visually-hidden context, `<details>`, table, alt text — not keyword stuffing).
5. **AGENTS.md applies.** Read `docs/player-journeys.md` before touching menu guidance wording; keep translation episodes locked.
6. **One round = one diff, one build, one verification log.** No drive-by edits.

---

## 1. Roles

**Builder** (one agent, full repo access)
- Picks the top 3 P0/P1 items from the critic report, fixes them at the source, rebuilds, re-verifies.
- May not argue with a critic. Only: fix, or file a **rebuttal** with evidence (file:line or command output) that the finding is factually wrong.
- Writes the round log: what changed, why, the exact verification command for each claim.

**Critics** (five, independent, read-only, fresh context each round)

| # | Critic | Only looks at | Fails the round if |
|---|--------|---------------|--------------------|
| C1 | Crawler access | `robots.txt`, headers, raw `curl` HTML with JS disabled | Key facts absent from raw HTML, AI bots blocked, sitemap/IndexNow broken |
| C2 | Structured data | JSON-LD blocks, schema.org validity | Invalid JSON-LD, missing entity graph, `sameAs` missing |
| C3 | Entity & links | naming consistency, internal anchors, cross-property links | Name variants ("SOW", "Shadows of War", "shadowsofwar"), orphan pages, dead/redirecting links |
| C4 | Content & intent | H1/H2 structure, answer-first paragraphs, coverage per query | No direct answer to a core query, duplicate thin pages, no FAQ/how-to-play surface |
| C5 | Human conversion | 5-second test, mobile, proof, CTA path | Visitor cannot say what the game is + where to click; unverifiable claim on page |

Each critic returns:

```
FINDING <id> | severity P0/P1/P2 | axis | evidence (file:line or command output) | why it matters | minimal fix
```
plus a score 0–10 against the axis rubric. Scores need the evidence line that justifies them.

---

## 2. Rubric — what a 10 looks like per axis

**C1 Crawler access (10)** — `curl -s https://shadowsofwar.io/ | sed 's/<[^>]*>//g'` yields the game's name, genre, platforms, price model, how a match works, and at least one screenshot alt. `robots.txt` explicitly allows `GPTBot`, `OAI-SearchBot`, `ClaudeBot`, `PerplexityBot`, `Google-Extended`, `Bingbot` (or `*` with no rule that hits them); blocks only `/api/`, `/internal/`, build artifacts. `sitemap.xml` `lastmod` is current and matches real edits. IndexNow key file is served at root and pinged on deploy.

**C2 Structured data (10)** — Valid `VideoGame` (`name`, `description`, `genre`, `gamePlatform`, `playMode`, `applicationCategory`, `operatingSystem`, `offers`, `image`, `screenshot`, `url`, `inLanguage`, `publisher` → `Organization` with `sameAs` to GitHub/Discord/X). Plus `WebSite` (with `potentialAction` only if a real search exists) and `FAQPage` matching visible FAQ text 1:1. Zero fields describing things the page does not show.

**C3 Entity & links (10)** — One canonical string for the game, one for the studio (World of Unreal), one for the domain, used identically in title/OG/JSON-LD/footer. `sameAs` set resolves (no 404, no 301 chains). Descriptive anchor text for internal links (`/play/`, leaders, maps, support). No page is reachable only from JS. Cross-links to cosmicrafts / nftropoly / WOU ID only where the relationship is real.

**C4 Content & intent (10)** — Each core query has a page or a section that answers it in the first two sentences: *what is it*, *how does a match work*, *is it free / where can I play*, *which leaders/maps*, *who makes it*. H2s are question-shaped or noun-shaped, not slogans. Lists and tables where comparison is the point (leaders, maps, platforms). One authoritative page per intent — no near-duplicate landing variants.

**C5 Human conversion (10)** — 5-second test: a stranger names the genre, the hook, and the next click. Above the fold: what it is, what you do, Play. Mobile/TestFlight badges honest about alpha status. Proof is real (screenshots, gifs, devlog, Discord) — never a number the repo cannot back. Reading level stays human; no "unlock the ultimate battlefield experience".

**Gate:** round passes only when **every** critic ≥ 8, **zero** open P0, and the builder's verification log reproduces every claim. Max 4 rounds; if round 4 fails, stop and report the unresolved axes instead of looping forever.

## 3. Round protocol

**R0 — Baseline (no edits).** Run the audit, publish the report. Expected starting inventory (verify, don't trust):

- `dist/web/robots.txt` uses `User-agent: *` with no AI-bot groups; `llms.txt` absent; `sitemap.xml` `lastmod` at 2026-08-25 looks stale versus `sow-web/site/` mtimes.
- IndexNow key file `8d227b8f9e6140d39e3381a1829e1db3.txt` exists at site root but nothing proves it is pinged on deploy.
- JSON-LD has `VideoGame` only; no `Organization` `sameAs`, no `WebSite`, no `FAQPage`, no `screenshot`.
- Page is i18n-driven (`data-i18n`, `SOW_SITE_LOCALE`) but there is no `hreflang` set and locale variants are not in the sitemap → per-locale discovery is invisible.
- No `/how-to-play/` or FAQ surface; the 3-step block is the only explanation of the loop.
- `play/` is the game shell: confirm what a crawler sees before WASM boots.

**R1–R4.** Builder fixes top P0/P1 → `./sow l` → critics re-audit from scratch (no memory of prior rounds, no sight of the builder's rationale) → gate.

**Verification commands (must appear in every round log):**

```bash
./sow l &                                    # local build on 127.0.0.1:4173
curl -s http://127.0.0.1:4173/ | sed 's/<[^>]*>/ /g' | tr -s ' \n' ' \n'
curl -s http://127.0.0.1:4173/robots.txt
curl -s http://127.0.0.1:4173/sitemap.xml | xmllint --noout -
curl -s http://127.0.0.1:4173/ | grep -c 'application/ld+json'
curl -sI http://127.0.0.1:4173/play/ | head -20
```

Prod re-check after `./sow p`: same curls against `https://shadowsofwar.io/`, plus a Rich Results / Schema validator pass on the live URL.

## 4. Anti-gaming rules

- Critics never see the builder's justification before scoring. Builder never sees which critic is weakest.
- No critic may raise a score because a fix "feels better"; only evidence in the new output counts.
- Fixed findings are re-tested by a **different** critic than the one that found them.
- Banned as "fixes": keyword stuffing, hidden text that repeats visible text, fake `aggregateRating`/`reviewCount`, schema for content not on the page, doorway pages per keyword, auto-generated city/keyword pages.
- A P0 cannot be downgraded to P1 by the builder; only the critic that filed it can close it.
- If two critics conflict, the human-page contract (§0.4) decides; log the conflict.

---

## 5. Deliverables per round

1. `docs/gauntlet/rN-report.md` — five critic reports verbatim, scores, gate verdict.
2. `docs/gauntlet/rN-log.md` — diff summary, per-claim verification command + output, rebuttals with evidence.
3. Rendered screenshots at 390 / 768 / 1440 px.
4. Final: a one-page changelog a human can read, and the list of axes still below 8 with the reason they were left.

---

## 6. Definition of done

A cold reader and a cold crawler independently produce the same four sentences: what the game is, what you do in a match, that it is free in the browser, and where to play. Every structured-data claim on the page is visible on the page. `robots.txt`, `sitemap.xml`, IndexNow and `hreflang` agree with what actually ships.
