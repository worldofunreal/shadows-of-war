# Leader copy template

One line per leader. Name + one bonus with a number. Nothing else.

## Format

`{Name} — {bonus with number}. {How it plays in ≤12 words}.`

- Keep the bonus identical in `web.toml` (`leader_*_multiplier`), the leaders page, and the store blurb.
- Second sentence is optional. If it repeats the bonus, delete it.

## Good

- `Ports generate +50% Gold. Ports also open water tiles.`
- `Armies fight 10% stronger. Lose fewer troops at borders.`

## Banned

`legendary`, `living world`, `conquer the world`, `mechanical multiplier`,
`civilizational`, `synergies`, `immersive`, `ultimate`, `epic`, em-dash drama.

## Checklist before merge

1. Bonus has a number (`+50%`, `10%`, `20%`).
2. No second sentence that restates the first.
3. Same wording in all 6 languages (or English fallback + translator pass).
