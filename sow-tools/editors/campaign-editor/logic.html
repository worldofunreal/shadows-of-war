Quick start
  1. Add and select a step; set its text key, speaker, and pacing in the inspector. Story copy lives in the shared language catalogs. For an objective or guide, use Pick target on map to assign a faction. Scenes wait for Continue; objectives wait for a game action; choose Wait (seconds) for a timed beat.
  2. Use Create next step on each decision answer to build its path in place, then connect paths where the story rejoins. The selected answer remains available to later scenes.
  3. Use a hand guide only to teach a mechanic or control. Decisions stay free of prompts; use the Language selector in the preview to check available catalog text.
  4. Preview the branching sample without changing this episode. Simulate choices and objectives, then return to your draft. Save, wait for the local update, and restart the episode in the game.
